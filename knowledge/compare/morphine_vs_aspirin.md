# 吗啡 vs 阿司匹林（镇痛）

| 维度 | 吗啡 | 阿司匹林 |
|---|---|---|
| 作用部位 | 中枢（脊髓胶质区、丘脑内侧、脑室及导水管周围灰质）阿片受体 | 主要外周：抑制炎症部位PG合成 |
| 机制 | 激动μ受体，抑制痛觉传入、改变痛情绪 | 抑制COX，减少PG（PG使痛觉感受器致敏） |
| 镇痛强度 | 强（效能高） | 中等 |
| 适用疼痛 | 各种剧痛（创伤、癌痛、心梗） | 慢性钝痛（头痛、牙痛、关节痛、痛经），对锐痛和内脏绞痛无效 |
| 其他作用 | 镇静、欣快、呼吸抑制、镇咳、缩瞳 | 解热、抗炎抗风湿、抗血小板 |
| 主要不良反应 | 呼吸抑制、便秘、**成瘾性/依赖性**、耐受 | 胃肠道反应、出血、阿司匹林哮喘、瑞夷综合征，无成瘾性 |
