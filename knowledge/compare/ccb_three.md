# 硝苯地平 vs 维拉帕米 vs 地尔硫䓬

|---|---|---|---|
| 扩张血管 | +++ | + | ++ |
| 心脏抑制（自律性、传导、收缩） | 弱（反射性心率↑） | +++ | ++ |
| 变异型心绞痛 | **首选**之一 | 可用 | 可用 |
| 稳定型心绞痛 | 宜合用β阻断药 | 可用 | 可用 |
| 抗心律失常 | 无 | **室上速首选** | 可用 |
| 与β阻断药合用 | 好（互补） | **避免**（传导阻滞） | 慎用 |
