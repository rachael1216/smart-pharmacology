# 竞争性 vs 非竞争性拮抗药

| 维度 | 竞争性拮抗药 | 非竞争性拮抗药 |
|---|---|---|
| 结合位点 | 与激动药同一受体位点 | 不可逆结合或别构位点 |
| 结合性质 | 可逆 | 常不可逆 |
| 激动药量效曲线 | 平行右移 | 右移且压低 |
| 最大效应 | 不变 | 降低 |
| 加大激动药剂量 | 可完全克服 | 不能恢复最大效应 |
| 强度参数 | pA₂ | pA₂′ / pD₂′ |
| 代表 | 阿托品（M）、酚妥拉明（α） | 酚苄明（α） |
