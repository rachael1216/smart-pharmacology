# 一级 vs 零级动力学消除

| 维度 | 一级（恒比） | 零级（恒量） |
|---|---|---|
| 消除速率 | 与浓度成正比 dC/dt = −kC | 恒定 dC/dt = −k₀ |
| t₁/₂ | 恒定 0.693/k，与剂量无关 | 不恒定，随剂量增大而延长 |
| 半对数作图 | 直线 | 曲线 |
| 转运方式 | 被动转运为主 | 主动转运/酶饱和 |
| 典型 | 绝大多数药物常用量 | 乙醇、大剂量苯妥英钠、阿司匹林 |
| 达稳态 | 约5个t₁/₂ | 剂量过大时无稳态，浓度急剧升高 |
