# 抗菌机制五类与30S/50S

| 靶点 | 药物 |
|---|---|
| 细胞壁 | 青霉素类、头孢菌素类、碳青霉烯、万古霉素、磷霉素、杆菌肽 |
| 胞质膜 | 多黏菌素（细菌）；两性霉素B、制霉菌素（真菌） |
| 核糖体30S | 氨基糖苷类、四环素类 |
| 核糖体50S | 大环内酯类、氯霉素、林可霉素/克林霉素 |
| 核酸 | 喹诺酮（DNA回旋酶/拓扑异构酶Ⅳ）、利福平（RNA聚合酶）、甲硝唑 |
| 叶酸 | 磺胺（二氢蝶酸合酶）、TMP / 乙胺嘧啶（二氢叶酸还原酶） |

口诀：**“三十而立（氨基糖苷、四环素），五十知天命（红霉素、氯霉素、林可霉素）”**。
