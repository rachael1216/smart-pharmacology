# 绝对 vs 相对生物利用度

| | 绝对生物利用度 | 相对生物利用度 |
|---|---|---|
| 公式 | AUC(血管外)/AUC(静注) ×100% | AUC(受试制剂)/AUC(标准制剂) ×100% |
| 比较对象 | 不同给药途径 | 同一途径不同制剂/厂家/批号 |
| 用途 | 评价吸收程度、首过效应 | 评价制剂质量、一致性评价 |
