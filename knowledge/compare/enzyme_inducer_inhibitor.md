# 肝药酶诱导剂 vs 抑制剂

| 维度 | 诱导剂 | 抑制剂 |
|---|---|---|
| 对肝药酶 | 活性↑ / 合成↑ | 活性↓ |
| 合用药血药浓度 | ↓，药效减弱 | ↑，药效增强甚至中毒 |
| 自身 | 可加速自身代谢 → 耐受 | — |
| 代表 | 苯巴比妥、苯妥英钠、利福平、卡马西平 | 西咪替丁、氯霉素、异烟肼、红霉素、酮康唑 |
| 典型案例 | 苯巴比妥 + 华法林 → 抗凝减弱 | 氯霉素 + 双香豆素 → 出血 |
